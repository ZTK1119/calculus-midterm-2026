# 高等数学上期中复习

六天学习网站，适用于手机、iPad和电脑。

- 函数、极限、连续、导数与微分
- 每天120分钟的任务、知识讲解、练习和分步答案
- 可用洛必达，不安排泰勒
- 复盘保存在当前浏览器，可导出TXT和备份JSON，跨设备需自行导入备份

网页来源于个人复习包。原始讲义、带手写信息的作业照片、个人记录及本机路径索引不包含在仓库中。题目出处标注在各题下方；来源材料的权利归原权利人所有。KaTeX遵循assets/katex/LICENSE.txt。
